# Security Policy

## Reporting a Vulnerability

Please do not publish sensitive vulnerability details in a public issue. Use GitHub's private vulnerability reporting feature for this repository when available.

Include the affected browser, reproduction steps, expected behavior, actual behavior, and any proof-of-concept material needed to understand the issue. Please avoid including real interview answers or other private session data in a report.

## Data Model

Drill Room is a client-only application. It does not have a backend, user accounts, analytics, or network integrations. Session content is stored locally in the browser. Security reports are therefore most likely to concern browser storage, clipboard behavior, pasted content, or unsafe rendering.
